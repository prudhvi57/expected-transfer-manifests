# Contributing

Submit reproducible bug cases with a minimal synthetic manifest, events, as-of
instant and expected findings. Run tests, optional schema validation, and
`python verify.py` before opening a pull request. Do not add credentials,
private logs, employer data, or claims of adoption that cannot be substantiated.
Explain human design, review and AI assistance accurately in contribution notes.

The spec is versioned separately from dataset generation. Changes to existing
benchmark data require updated version/provenance notes; do not silently replace
published results. Preserve original failures in regression tests. Genuine external
usage and feedback may be documented with permission and verifiable references.
