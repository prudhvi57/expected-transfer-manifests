# Paper experiment

This folder holds the synthetic experiment reported in the paper
"Expected Transfer Manifests for Scheduled Enterprise Data Transfers:
A Review and Reference Architecture" (P. R. Katragadda).

`etm_sim.py` generates metadata logs for 300 synthetic feeds (weekly, daily and
near real time) across five time zones. It learns a manifest per feed from an
8 week training period, then reconciles a 17 week test period that spans US and
UK daylight saving changes, three holidays, a collector outage, a legitimate
schedule change and injected faults. It compares the result with static rule
baselines in UTC and in local time. Five seeds are aggregated.

```sh
python paper-experiment/etm_sim.py      # prints the aggregated results (about 40 s)
python paper-experiment/check.py        # reruns and compares with results.json
```

Key numbers in `results.json`:

| Measure | Value |
|---|---|
| Injected faults alerted | 556 of 563 |
| Faults hidden by the collector outage, reported as monitoring gaps | 7 |
| False alerts, static UTC baseline | 11,623 |
| False alerts, static local time baseline | 802 |
| False alerts, ETM (all from the schedule change) | 111 |

`detection` entries are `[injected, alerted, reported as monitoring gap]`.
Timing fields vary by machine and are not part of the reproducibility check.

All data are generated by the script. No real systems, partners or logs were used.
The repository root holds a smaller, separate conformance benchmark for the
manifest specification; its scores are not the paper's results.
